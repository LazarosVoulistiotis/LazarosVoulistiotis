# Hi, I'm Lazaros 👋

**Final-year BSc Computer Science candidate** focused on **applied machine learning**, **backend engineering**, and **production-inspired software systems**.

I build practical, data-driven applications that combine clean architecture, reliable APIs, secure authentication, database design, model evaluation, explainability, and strong technical documentation. My work spans **machine learning**, **fraud detection**, **distributed mobile systems**, **Android development**, **cybersecurity labs**, and **full-stack database-backed applications**.

I am especially interested in transforming machine learning experiments into **deployable, explainable, and operationally useful systems**.
